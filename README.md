Debt Notes is a lightweight and privacy-focused Android application designed to help you easily manage personal debts, expenses, and payment records.
Keep track of money you have lent or borrowed, maintain organized records, and quickly review your financial activities from a clean and intuitive interface.

**✨ Key Features**
📝 Create and manage debt records
💰 Track lending and borrowing
📊 Manage expenses and payment details
🖼️ Add images to records
✍️ Signature support for records
🔔 Notifications for important reminders
🌙 Dark Mode and Light Mode
🎨 Customizable interface colors
🌐 English, Telugu & Hindi support
🔒 Privacy-focused and secure design
⚡ Fast and responsive interface
📱 Optimized for Android devices
💾 Local data management for offline usage

Debt Notes is built with simplicity in mind, making it easier to maintain your financial records without unnecessary complexity.
